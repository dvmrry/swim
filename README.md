# swim

Minimalist, keyboard-driven, vi-modal web browser for macOS — written in Swift.

Under construction. This is a clean-room Swift rewrite of the original C/Objective-C
swim, which is archived at [dvmrry/swim-c](https://github.com/dvmrry/swim-c)
(tag `c-final`) and serves as the reference implementation.

Start with [`docs/SPEC.md`](docs/SPEC.md): data-compatibility requirements,
feature parity checklist, day-one architecture, and non-goals.
